Put your video here and name it:   cinema-loop.mp4

- H.264 video + AAC audio (stereo) in an .mp4 container works in every browser.
- Any length. It loops forever.
- 16:9 works best (the screen is 12 m x 6.75 m).
- Keep it under ~100 MB so it loads quickly.

If this file is missing, the app shows a built-in demo screen with a
generated test soundtrack, so you can still try walking, sitting and spatial audio.
